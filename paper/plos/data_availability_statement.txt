DATA AVAILABILITY STATEMENT
(Enter this text in the "Data Availability" section of the PLOS ONE submission form.)

All data and code underlying the findings are fully available without restriction.

Code. The MI-Workbench source code (platform, agent prompts, workflow presets, all evaluation harnesses, figure scripts and the test suite) is available under the MIT license at https://github.com/Biodyn-AI/mi-workbench. The release described in the paper (v1.1.0) is archived on Zenodo at https://doi.org/[ZENODO DOI — to be inserted by the author after the release is archived]. Step-by-step instructions to reproduce every experiment are in docs/REPRODUCING.md.

Data. All data generated in this study are included in the Supporting Information: the planted-flaw benchmark with ground truth and the pre-specified analysis plan (S1 File); raw reviewer outputs, judge labels, adjudications, revision-loop trajectories and state judgments, with the analysis scripts and processed results (S2 File); and the case-study materials, including the data-kit construction and independent-analysis code with results, the agent runs with all iterations and execution outputs, and the number trace (S3 File). Run settings and token usage are listed in S1 Table and all numerical results in S2 Table.

Third-party data and models. The case study uses publicly available data and models: the Tabula Sapiens immune data (Tabula Sapiens Consortium, Science 2022; https://tabula-sapiens-portal.ds.czbiohub.org), Geneformer V2-104M (Theodoris et al., Nature 2023; https://huggingface.co/ctheodoris/Geneformer, snapshot fcd26c45fc30fba1989e586bdc46bc366dda8655), TRRUST v2 (https://www.grnpedia.org/trrust/) and DoRothEA. The large derived attention and co-expression arrays (about 2.6 GB) are regenerated from these sources by experiments/case_study/build_kit.py; their checksums are recorded in the kit manifest in S3 File.

Language models. All language-model calls used OpenAI models through the Codex command-line interface (version 0.145.0); model names, reasoning-effort settings and token counts for every experiment are listed in S1 Table. No human-subjects data were generated.
