# Verification: A01 (Geneformer V2-104M attention heads vs TRRUST in PBMCs)

Files: `artifacts/A01-flawed.md`, `artifacts/A01-clean.md`, `ground_truth/A01-flawed.json`, `ground_truth/A01-clean.json`.

Verdict: FIXED. There were three small edits to the flawed artifact and two to the clean one. No ground-truth changes were needed.

## Checks
1. **Quotes.** All 4 ground-truth quotes match the artifact verbatim, and each occurs exactly once (checked in Python after the edits). F1 is in Results, F2 and F3 are in Interpretation, and F4 is in Methods. None is in Limitations. The JSON parses, the family labels match the types, and the clean file has `"flaws": []`.
2. **Planted flaws.**
   - F1 S1: "19 of the 144 heads showed significant enrichment (permutation p < 0.05)". The 144 tests are stated outright, and no correction appears anywhere. About 7.2 heads are expected by chance, and with 1,000 permutations the minimum p (about 0.001) cannot pass Bonferroni (3.5e-4). Valid. The criterion requires the missing correction across heads.
   - F2 C1: the degree-preserving null is taken to show "pair-specific regulatory relationships". Co-expression and expression level are never mentioned, and the top pairs (CIITA–HLA-DRA, SPI1–CSF1R) are co-expressed cell-type programs. The null already controls degree, so this is not C2. Valid. The criterion requires co-expression or expression confounding to be named.
   - F3 L1: the heads are called "the mechanism through which Geneformer uses ..." and "the model's internal regulatory circuit". No intervention was done. Valid and unhedged, and the criterion is strict.
   - F4 T1: the attention-symmetry error (A_ij = A_ji) is used to collapse directed TRRUST edges into unordered pairs. Valid, and the criterion requires the false premise to be identified.
   - None of the flaws is hedged or signposted. The Limitations entries (donors, TRRUST incompleteness, cell averaging, one model size) do not touch the flaws.
3. **Unplanned flaws.**
   - The Interpretation said the top TRRUST pairs being well-characterized immune programs "supports the biological relevance of the recovered edges". The recovered edges are TRRUST edges, so this evidence is not independent of the result, which is a mild L2 (circular validation). The clause is removed (see Fixes). The list of programs stays, because it helps a reviewer detect F2.
   - Results said "Enrichment was consistent across donors", based on per-donor AUPRCs of L9H4, a head selected on the pooled cells of those same donors. That wording read as independent validation (L2/C3-like). It is reworded as a plain descriptive statement.
   - No other instances found. The report includes AUPRC with the base rate, so S3 does not apply, and effect sizes are reported, so S2 does not apply. The null is degree-preserving (no C2). There is no train/test framing (no C3 beyond the selection effect covered by F1). All TF–target directions are correct (STAT1→IRF1, CEBPB→IL1B, CIITA/RFX5→MHC-II), so B1/B2 do not apply.
4. **Model facts.** Correct: V2-104M has 12 layers, 12 heads and 768 d, is pretrained on masked genes, uses rank-value tokenization with normalization by the non-zero median, and has a 4,096-token context. The 4,000-gene QC cap fits in that context.
5. **Clean counterpart.** All four flaws are fixed:
   - BH-FDR across the 144 heads, with 10,000 rewirings.
   - Co-expression and expression-level baselines, plus a residualized re-test.
   - Findings stated as associations, with ablation/patching named as the test.
   - A correctly described asymmetric, row-stochastic attention, with directed target-query → TF-key scoring.
   No flaw types were found. The reverse orientation and the residual tests are corrected within each family of 144 heads, and the magnitudes are interpreted in proportion. Length is 1,090 vs 937 words (ratio 1.16).
6. **Internal consistency.**
   - The unordered candidate count 118×2,096 + C(118,2) = 254,231 is right, as is the directed count 118×2,213 = 261,134.
   - Base rates are 0.40%.
   - The AUPRC-to-base-rate ratios in the flawed table match to rounding.
   - Layer counts of the 19 heads add up (1 + 0 + 14 + 4).
   - In the clean version the BH q-values are compatible with 10,000 permutations, and the CIs contain their point estimates.
7. **Meta-commentary.** None.

## Fixes made
- A01-flawed Methods: the candidate-set count (254,231) was the unfiltered total even though 0.6% of pairs were dropped. It now reads "that passed the co-presence filter (252,706 of 254,231 pairs)". The base rate is still 0.40%.
- A01-flawed Results: "Enrichment was consistent across donors: recomputing L9H4 scores within each donor gave AUPRCs between 0.0109 and 0.0133." now reads "Recomputed within each donor, L9H4 gave AUPRCs between 0.0109 and 0.0133." This removes the implicit validation claim.
- A01-flawed Interpretation: removed ", which supports the biological relevance of the recovered edges" (unplanned circular validation).
- A01-clean Methods: the same count fix, "(259,567 of 261,134 pairs)", with the base rate still 0.40%.
- A01-clean Interpretation: "No enrichment was seen in the randomly initialized model." now reads "The randomly initialized model showed no comparable enrichment." The random model was only described by its maximum AUPRC ratio, and no significance test on it was reported.

## Residual concerns
- A strict reviewer may still raise the selection of the top five heads without a held-out check as C3. The F1 description counts that selection effect as part of the multiplicity flaw, so the judge may map such a critique to F1 or label it substantive.
- The F1 description says "~7 expected by chance". Because 19 is more than 7, some true global signal is plausible. The flaw is the per-head calls, not the existence of any signal. The criterion is worded correctly for this.
