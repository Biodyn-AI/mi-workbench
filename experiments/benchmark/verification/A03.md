# Verification: A03 (linear probing of Geneformer V1-10M layers for immune cell type, Tabula Sapiens)

Files: `artifacts/A03-flawed.md`, `artifacts/A03-clean.md`, `ground_truth/A03-flawed.json`, `ground_truth/A03-clean.json`.

Verdict: FIXED (ground truth only). The detection criterion for F4 (T2) was made applicable consistently. No artifact text changed.

## Checks
1. **Quotes.** All 4 ground-truth quotes match the artifact verbatim, and each occurs exactly once (checked in Python). F1 is in Results, F2 in Methods, F3 in Interpretation, and F4 in Data and model. None is in Limitations. The JSON parses, and the clean file has `"flaws": []`.
   - The IDs in the ground truth differ from the author's summary: the JSON has F1 = S2, F2 = C3, F3 = L1 and F4 = T2. The JSON is internally consistent, so nothing needs to change.
2. **Planted flaws.**
   - F1 S2: macro-F1 0.921 vs 0.917 (Δ 0.004), p = 0.003 from a cell-level bootstrap over 12,284 cells, is read as "information beyond expression alone". The effect is negligible and no CI is given. Valid, and the criterion is tied to this comparison.
   - F2 C3: cells from all 15 donors are pooled and split at random, the cross-validation is at the cell level, and the text then recommends layer 4 "for annotating immune cells from new donors". Valid. The criterion requires the shared-donor argument plus a donor-grouped remedy.
   - F3 L1: "computes an explicit cell-type representation ... uses it to drive masked-gene prediction ... which is why decodability declines". This is a causal claim based on probing alone. Valid, and the criterion is strict.
   - F4 T2: Geneformer is described as adding expression-bin embeddings, which is scGPT's scheme; Geneformer actually uses rank-value encoding. This premise is used to treat layer 0 as an expression reference and to credit the gain over layer 0 to cross-gene integration, so the error matters for the logic. Valid.
   - None of the flaws is hedged or signposted, and Limitations (label granularity, class capping, pooling, linear probes) do not touch them.
3. **Unplanned flaws.** None found.
   - Macro-F1 and balanced accuracy suit the imbalanced classes, so there is no S3.
   - The scaler, HVG selection and PCA are fit on training cells, and the layer is selected by cross-validation on training cells, so there is no test-set selection. The residual leakage (cells shared across donors) is F2 itself.
   - Only one inferential test is reported, so there is no S1.
   - The cell types and confusion pairs are plausible, so there is no B1/B2.
4. **Model facts.** Correct apart from the planted F4: V1-10M has 6 layers, 4 heads, 256 d and a 2,048-token context, and it was pretrained with masked-gene prediction on Genecorpus-30M (about 30M cells). Mean pooling is used because V1 has no CLS token, and there are 7 hidden states.
5. **Clean counterpart.** All four flaws are fixed:
   - Nested cross-validation grouped by donor (5 outer folds × 3 donors) with donor-bootstrap CIs.
   - The baseline difference is read as practically equivalent (0.004, CI −0.012 to 0.020).
   - The claims are about decodability only, with an intervention named.
   - Rank-value encoding is described correctly, including what mean-pooled layer 0 loses.
   No flaw types were found: two prespecified contrasts are reported with CIs and not with uncorrected p. Length is 997 vs 873 words (ratio 1.14).
6. **Internal consistency.**
   - 49,136 + 12,284 = 61,420.
   - The random-init gaps are 0.219 and 0.191.
   - The flawed per-class F1 values can reach macro-F1 0.921: the remaining five classes need a mean of about 0.95, all at or below 0.96. The clean values can reach 0.874: the remaining five need a mean of about 0.91.
   - In the clean version the selected-layer 0.873 is consistent with layer 4 at 0.874, the final-layer contrast is 0.873 − 0.852 = 0.021, and the CIs contain their point estimates.
7. **Meta-commentary.** None.

## Fix made
- ground_truth/A03-flawed.json, A03-F4 detection_criterion: the old criterion required the critique to state both that the tokenization was wrong and that, as a consequence, layer 0 carries no per-gene expression. A critique that correctly identified the rank-value vs binning error in this passage could therefore be rejected. The core requirement is now to identify the tokenization description as factually wrong. Linking it to the invalid layer-0 "expression reference" is now expected but not required. Critiques that only question the layer-0 baseline, without the tokenization error, still do not qualify.

## Residual concerns
- F1 (S2) and F2 (C3) both touch the cell-level bootstrap. A critique saying only "the bootstrap over non-independent cells inflates significance" satisfies neither criterion on its own. The judge should map it to F1 only if it also calls the 0.004 gap negligible, and to F2 only if it names the shared-donor split. This is intended, but judges should be told about it.
