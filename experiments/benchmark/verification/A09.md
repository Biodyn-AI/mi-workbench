# Verification: A09 (donor-age axis in Geneformer V2-104M PBMC embeddings)

Files: `artifacts/A09-flawed.md`, `artifacts/A09-clean.md`, `ground_truth/A09-flawed.json`, `ground_truth/A09-clean.json`.

Verdict: FIXED (length parity and one ambiguity). No ground-truth changes were needed.

## Checks
1. **Quotes.** All 4 flawed ground-truth quotes match the artifact verbatim, and each occurs exactly once. The clean ground truth has `"flaws": []`.
2. **Planted flaws.**
   - F1 C3: a random cell-level 80/20 split, with cell-level inner CV, puts the same donors in train and test for a donor-level label. Valid, and the criterion requires a donor-grouped remedy.
   - F2 S3: 97.4% accuracy at 3.2% prevalence (4,563/142,870). The trivial baseline is about 96.8%. Valid and strict.
   - F3 B2: CDKN2A/p16INK4a is described as "driving G1-to-S entry". It is a CDK4/6 inhibitor, so the sign is reversed. Valid and strict.
   - F4 L1: "Geneformer has learned to compute donor age ... the model uses ..." rests on decodability and correlations alone. Valid, and the criterion requires a call for interventions.
   - None of the flaws is hedged or mentioned in Limitations.
3. **Unplanned flaws in the flawed version.** The PC baseline did not say where the PCA was fitted, which a hostile reviewer could read as a separate "fitted on all data" C3. Fixed (see below). Everything else is either part of the planted C3 (cell-level bootstrap, cell-level oldest-donor split) or benign. BH is applied over the stated 86,800 = 12,400 x 7 tests, so there is no S1. The strongly discussed correlates have |rho| of 0.2-0.4, so there is no S2. The immune-aging genes (GZMH, NKG7, KLRD1 up; CCR7, LEF1, SELL, CD28 down; S100A8, IL1B in monocytes) are plausible.
4. **Model facts.** Geneformer V2-104M (12/12/768), rank-value encoding, 4,096 tokens, and the penultimate-layer mean embedding are all correct in both versions.
5. **Clean counterpart.** It fixes all four flaws: donor-grouped 5-fold CV with inner grouped CV and PCA and covariate regression fitted on training donors; a donor-level oldest-donor classifier with AUPRC vs the 0.032 prevalence, AUROC, balanced accuracy and sensitivity/precision at 90% specificity; correct p16 biology; association-only wording with out-of-fold projections. It also adds composition-only and PC baselines with paired-bootstrap Δr. No instance of the 12 types was found. The numbers check out: 31/981 = 0.032; 16/31 = 0.52; 95 of 950 false positives is 10%; precision 16/111 = 14%; AUPRC/prevalence is about 6; 0.71 - 0.64 = 0.07. The table cell counts sum to 142,870 and are exactly 5x the flawed version's test-cell counts. The flawed test counts sum to 28,574.
6. **Realism and internal consistency.** Train 114,296 + test 28,574 = 142,870 (80/20). The CIs contain their point estimates.
7. **Meta-commentary.** None.

## Fixes made
- **Length parity.** The clean version (1082 words) was 26.7% longer than the flawed one (854 words), beyond the ~25% tolerance.
  - Trimmed the clean version: condensed the within-type sentence, the interpretation increment sentence, the CDKN2A sentence, the |rho| wording and the 0.5-cutoff phrase.
  - Replaced the clean version's fourth limitation ("No in silico perturbation or ablation was performed ...") with the same frozen-model limitation the flawed version uses. The old limitation was redundant with the Interpretation's association-only wording, and it made the clean version easy to tell apart. The clean version now reads "adds only a modest increment over the PC baseline", which removes an ambiguity.
  - Added one benign realism clause to the flawed age-regression result (predictions compressed toward the cohort median).
  - Result: 878 words (flawed) vs 1060 (clean), ratio 1.21.
- **Flawed PC baseline.** Added "(PCA fitted on the training cells)", so the only leakage left is the planted donor-overlap split.
